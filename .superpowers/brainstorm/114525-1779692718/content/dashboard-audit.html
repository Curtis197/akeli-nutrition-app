Dashboard Audit — What's There vs. What's Missing

Does the current home page give users enough to understand their progress?

✅ What the dashboard shows

Current weight vs. target weight (progress circle)
Today's calories consumed (vs. hardcoded 2000 kcal target)
Today's planned meals (horizontal scroll)
Shopping list preview (top 4 items, filterable)
Recommended recipes (personalised feed)

❌ What's missing for progress insight

No macro breakdown — protein, carbs, fat are tracked in DB but never shown
No trend data — everything is today-only; no 7-day calorie or weight curve
Hardcoded calorie target (2000 kcal) — not pulled from the user's nutrition plan
No streak / adherence — user can't tell if they're consistent week-to-week
Weight stepper is UI-only — not persisted to Supabase
Verdict: The dashboard is a good daily snapshot but gives zero trend visibility. A user can't answer "Am I improving over time?" from the home page alone. The graph/progress page will fill exactly that gap.
